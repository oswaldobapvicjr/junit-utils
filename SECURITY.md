# Security Policy

## Supported Versions

| Version     | JDK version(s) | JUnit version(s) | Supported          |
| ----------- | -------------- | ---------------- | ------------------ |
| **1.10.0**  | 8, 11, 17, 21  | 5+               | :white_check_mark: |
| 1.7.0~1.9.0 | n/a            | n/a              | :x:                |
| **1.6.1**   | 8, 11, 17, 21  | 4, 5+            | :white_check_mark: |
| < 1.6.1     | n/a            | n/a              | :x:                |


## Reporting a Vulnerability

We take security seriously and appreciate your efforts to disclose any issues responsibly.

- Please **do not** open a public GitHub issue for security vulnerabilities.
- Instead, report vulnerabilities privately using GitHub’s [private vulnerability reporting](https://github.com/oswaldobapvicjr/junit-utils/security/advisories/new).

When reporting, please include:
- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

We will confirm receipt as soon as possible, investigate, and share an update on the resolution timeline.

## Security Updates

- Critical fixes will be released as patch versions (e.g., `1.10.x`).
- Non-critical issues may be scheduled for the next minor or major release.
- Security advisories will be published via GitHub’s [Security Advisories](https://github.com/oswaldobapvicjr/junit-utils/security/advisories).

## Responsible Disclosure

We kindly ask that you:
- Give us reasonable time to address the issue before public disclosure.
- Avoid exploiting vulnerabilities in production systems.
- Coordinate with us to ensure users are protected.

Thank you for helping keep **junit-utils** secure!
